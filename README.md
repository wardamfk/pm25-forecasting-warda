
# PM2.5 Forecasting Project

## Project Overview
This project focuses on the analysis and forecasting of PM2.5 air pollution using historical air quality data.

## Objectives
- Audit and clean the original datasets.
- Perform exploratory data analysis (EDA).
- Analyse correlations and feature relationships.
- Study temporal patterns and stationarity.
- Develop and evaluate forecasting models.

## Project Structure
- `data/`: Raw and processed datasets (not tracked by Git).
- `notebooks/`: Jupyter notebooks.
- `src/`: Python source code.
- `scripts/`: Execution scripts.
- `folds/`: Data split definitions.
- `results/`: Analysis outputs and model results.
- `figures/`: Generated figures.
- `reports/`: Technical report.
- `presentation/`: Project presentation.
